# 🌐 Lin Thant Kyaw – Portfolio Website

A modern, responsive personal portfolio website built using **HTML**, **CSS**, **Bootstrap**, and **JavaScript**.

## 🚀 Overview
This project showcases my skills, education, and personal projects in an elegant glowing dark theme.  
It includes animated sections, Bootstrap components, and smooth transitions for a professional presentation.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Framework:** Bootstrap 4.6
- **Libraries:** Typed.js, Font Awesome
- **Testing Environment:** XAMPP / Localhost
- **Deployment:** GitHub Pages

## 📂 Project Structure
```
.
├── index.html
├── style.css
├── script.js
└── background.png
```

## 🧩 Main Sections
- **Home:** Animated intro with Typed.js text  
- **About:** Short introduction and background  
- **Skills:** Technical skill set with icons  
- **Projects:** Portfolio of past works  
- **Client Reviews:** Carousel with ratings  
- **Contact:** Message form  
- **Footer:** Copyright section  

## ✨ Features
- Smooth scroll animations (IntersectionObserver)
- Bootstrap carousel for reviews
- Progress bars showing client satisfaction
- Fully responsive design
- Glowing highlight color: `#30AE80`

## 🧠 How to Run
1. Download or clone this repository:
   ```bash
   git clone https://github.com/<yourusername>/portfolio.git
   ```
2. Open `index.html` in any browser or serve via XAMPP:
   ```
   http://localhost/portfolio/
   ```
